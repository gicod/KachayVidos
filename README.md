# Video Downloader — прототип

Настольный прототип на Python + PySide6:
- тёмная тема;
- отдельные каталоги YouTube и Instagram;
- выбор качества отдельно для каждой платформы;
- вставка нескольких URL (по одному на строку);
- очередь задач, прогресс и журнал;
- настройки сохраняются в `config/settings.json`.

## Запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Для реальной загрузки видео с YouTube/Instagram установите FFmpeg и добавьте его в PATH.
Загружайте только контент, к которому у вас есть разрешённый доступ.

## Примечания
Это ранний прототип. Загрузка выполняется через `yt-dlp`; поддержка Instagram зависит
от доступности публикации и требований платформы. Для приватных материалов может
потребоваться отдельная настройка авторизации. Не обходите ограничения доступа.

## Вкладка «Логи»

Вкладка показывает события приложения и диагностику `yt-dlp`: уровень сообщения, время, идентификатор задачи, параметры команды (эквивалент CLI), предупреждения и исходные технические ошибки. Для удобства предусмотрены поиск, фильтр по уровню, копирование видимых записей и экспорт в `.log`/`.txt`. Часть распространённых ошибок сопровождается пояснением на русском языке.

> Примечание: команда отображается как эквивалентный набор параметров, поскольку приложение вызывает `yt-dlp` через Python API, а не запускает отдельную команду оболочки.
